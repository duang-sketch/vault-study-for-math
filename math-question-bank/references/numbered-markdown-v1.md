# numbered-markdown/v1 —— 题库集合格式契约

约定刻意做得很小：任何工具都能生成、能解析、能用 `grep` 查。

```markdown
# 集合标题

## 第一章 函数与极限

### 12
> 原编号 1.1.2.1.4 ｜ 年份 2016
> 标签：知识块=极限与连续 ｜ 类型=计算 ｜ 来源=考研真题 ｜ 难度=3星
<!-- source-page: 27 -->

题干文字（公式走样时用净通道重录）
```

## 规则

| 元素 | 约定 |
|---|---|
| `# ` | 集合标题，整个文件一个 |
| `## ` | 章节 / 考点分组，可多层 |
| `### <纯数字>` | 一道题，**编号必须是纯数字**（`12`、`13.1`），不要带 `例`、`习题` 等字样 |
| `> ` 行 | 元信息与标签，紧跟在题号下面 |
| `<!-- source-page: N -->` | 1-based PDF 页码，**溯源的关键**，必须保留 |
| 集合目录 | 同时有 `.md` 与 `source-manifest.json` 才会被下游识别 |

## 标签行

`> 标签：知识块=X ｜ 类型=Y ｜ 来源=Z ｜ 难度=W`，四个字段都可缺省：

- **知识块**：函数性质 / 极限与连续 / 导数与微分 / 中值定理与导数应用 / 不定积分 / 定积分 /
  反常积分 / 定积分应用 / 微分方程 / 向量与空间解析几何 / 多元微分 / 重积分 / 曲线曲面积分 /
  无穷级数 / 线性代数 / 概率论与数理统计（+ 综合模拟 / 未分类）
- **类型**：选择 / 计算 / 证明（非逐题集合用 页码条目 / 专题题库）
- **来源**：考研真题 / 竞赛真题 / 题目汇编 / 自造 demo
- **难度**：来源级别（如 `3星`、`竞赛`、`考研真题`），不是逐题实测

## 为什么编号必须纯数字

下游按 `### <编号>` 切题，编号里混入中文（`### 例 1.1.1`）会让部分工具漏切。
原始编号（`例 1.1.1`、`习题 11`）请写进 `>` 元信息行，不要写进 `###`。
