# 题目收集：web 优先，先出处后内容

## 顺序

1. **先 Web**：用 Coding Agent 自带的 web search 去找公开题源——公开竞赛试题、高校公开题库、
   开放许可（CC / MIT / public domain）的讲义与习题集、作者本人公开的题集。
2. **后本地**：只有自有材料或已获授权的材料，才走本地 PDF 通道（`scripts/collect/from_pdf_*.py`）。
3. 本地通道产出的集合**默认只在自己机器上用**；要对外分发，先确认你对这些内容有分发权。

## 每条必须记录的溯源字段

| 字段 | 说明 | 缺失后果 |
|---|---|---|
| `source` | 来源名（如「2023 年 XX 竞赛初赛」） | 缺了直接拒绝收录 |
| `url` | 出处链接 | 缺失只警告，但无法复核 |
| `license` | 许可（`CC BY 4.0`、`public domain`、`unknown`…） | 未确认会警告；`--strict` 下拒绝收录 |
| `year` | 年份（可选） | —— |
| `section` | 归类（可选，缺省用 `--default-section`） | —— |

`scripts/collect/from_web.py` 会把这些写进条目：

```markdown
### 7
> 来源=2023 年 XX 竞赛初赛 ｜ URL=https://example.org/p/7 ｜ 许可=CC BY 4.0
> 标签：知识块=极限与连续 ｜ 类型=计算 ｜ 难度=竞赛
<!-- source: https://example.org/p/7 -->

求 $\lim\limits_{x\to 0}\dfrac{\sin x-x}{x^{3}}$。
```

## 什么不能做

- **不要**把受版权保护的教辅（含市售习题册、考研辅导书、竞赛辅导书）整本转录后公开分发。
- **不要**因为"网上能搜到 PDF"就当作可以转载；能找到 ≠ 有授权。
- **不要**丢掉出处。没有 `source-page` / `source` 的条目在复核时等于废条目。
- **不要**用 OCR 结果覆盖原意：宁可标 `[疑]` 并保留原文，也不要"顺手改错"。

## 许可速判

| 许可 | 能否再分发题目 | 备注 |
|---|---|---|
| CC0 / public domain | 可以 | 最安全 |
| CC BY / CC BY-SA | 可以 | 必须署名，SA 要求同许可分享 |
| MIT / Apache-2.0 / BSD | 可以 | 常见于开源题库、教材配套代码库 |
| CC BY-NC* | 非商业可用 | 商用场景避开 |
| 未标注 / 版权所有 | 不要分发 | 只在本地做个人学习索引 |
