# 两条通道：什么时候用哪个

同一本书，走哪条通道取决于**你拿题面去干什么**。

## 快通道：PDF 文本层

```
pdf_to_question_md.py / fence_to_question_md.py / competition_book_to_questions.py
```

- 用 `pdftotext`（或 MinerU 已产出的页段）直接切题
- **优点**：快，几分钟一本书；题号与页码通常是准的
- **缺点**：公式走样（`∫₀²x√(4−x²)dx` → `2 x 4-x2dx`）
- **适用**：建"题源索引"——知道**哪一页有什么题**，出题时回原页取题面

## 净通道：MinerU → 结构化题源库

```
mineru parse → pagekit.py → assemble.py → qa.py → anomaly.py
```

- MinerU 输出干净 LaTeX，再用脚本拼接、切题、合并解答、标页码
- **优点**：题面可直接使用；有 `[疑]` 标注与覆盖率巡检
- **缺点**：慢（CPU 上稠密页 5–15 秒/页），且需要人工设定章节表
- **适用**：要**直接拿来出题、印卷子**的题库

## 选择判据

| 你的目的 | 选哪条 |
|---|---|
| 想知道"这本书里有哪些题、在哪一页" | 快通道 |
| 要把题面抄进试卷、笔记 | 净通道（或快通道 + 逐题回原页） |
| 书没有文本层（纯扫描件） | 只能净通道 |
| 书是分块 PDF、一页多题 | 专题级/页级集合（快通道的两种特例） |

## 现有工具的粒度差异（重要）

| 粒度 | 含义 | 例 |
|---|---|---|
| 逐题 | 一题一条，可直接用 | 文本层切题、净通道切题 |
| 页级 | 一页一条，一条含多题 | `competition_book_to_questions.py` |
| 专题级 | 一条 = 一个专题 PDF 的指针 | `fence_to_question_md.py` |

后两种**不是逐题**，出题时要按条目里的路径/页码打开原文件。
