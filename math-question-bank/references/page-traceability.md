# 页码溯源：印刷页、PDF 页与 [疑] 标注

题库最大的价值不是"有题"，而是"**每条都能回到原书那一页核对**"。因为题面来自 PDF 文本层或 OCR，
公式一定会有走样的地方，出题前必须能快速回原页。

## 两个页码不是一回事

- **PDF 页**：扫描件的物理页序，从 1 开始，MinerU 用 `<!-- page N of M -->` 标出
- **印刷页**：书页页脚印的页码

两者差一个固定偏移（前面有封面、版权页、目录等）。偏移必须**实测量出来**，不能假设：

```bash
python assets/worked-example-chen-jixiu/offset_check.py        # 输出各页的候选页脚数字与偏移分布
```

实测例子（本项目整理过的两本书）：

| 书 | 关系 | 备注 |
|---|---|---|
| 数学分析习题全解指南（上） | 印刷页 = PDF 页 − 6 | 全册无例外；PDF p.1–6 是封面/目录 |
| 高等数学疑难问题选讲 | 印刷页 = PDF 页 − 16 | 按 `<!-- page N of 332 -->` 标记计算 |

## 每条题都要写页码

标题或元信息里写 `（来源：书 P.xx / PDF p.yy）`：

- `yy` 取**题面开始处**所在页的 `<!-- page N of M -->`
- `xx = yy − 偏移`
- 题面跨页时取开始页；解答延伸到范围外要抄完整

## `[疑]` 标注规则

遇到下列情况，**就地标 `[疑]` 加一句极简说明，不要自己改**：

- 数学符号明显被 OCR 认错（如 `e_0` 本应是 `\varepsilon_0`）
- `$`、`\left`/`\right`、括号不配对
- 极限上下标错乱、题号跳号或重复
- 题面与解答里的式子不一致
- 解答是图片（写 `[解答为图]`，不要自己补写）

写法的核心是**保留原文**，把判断留给复核的人：

```
取 $|x| > 1$，则 $\leqslant \frac{3}{2|x|$，于是 [疑：此处 $ 与 \right 均不配对]
```
